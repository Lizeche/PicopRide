# PicopRide — Web app demo

## Estructura
- `index.html`: estructura y contenido de la web app.
- `css/styles.css`: estilos separados y diseño adaptable.
- `js/app.js`: menú móvil, validación del formulario y gestión local de solicitudes.
- `assets/picopride-logo.png`: logo proporcionado.

## Cómo abrir en Visual Studio Code
1. Extrae `PicopRide_WebApp.zip`.
2. Abre la carpeta `PicopRide_WebApp` en Visual Studio Code.
3. Abre `index.html` en el navegador, o usa la extensión Live Server y pulsa **Go Live**.

## Funcionalidad incluida
- Diseño responsive para computadora y móvil.
- Navegación por secciones.
- Formulario con validación HTML.
- Creación y visualización de solicitudes de transporte.
- Guardado de solicitudes en `localStorage` del navegador.
- Opción para limpiar las solicitudes.

## Importante
Es un prototipo front-end: los registros se guardan solamente en el navegador del dispositivo y no se envían a conductores reales. Para operar de verdad se necesitarían backend, base de datos, autenticación, ubicación/mapas, sistema de cotizaciones, notificaciones y controles de privacidad.
